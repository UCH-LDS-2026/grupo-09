## Nombre del proyecto
**Simulador interactivo de sistemas distribuidos**

## Descripción
El proyecto consiste en una aplicación web que permita diseñar y simular arquitecturas de sistemas distribuidos de forma visual e interactiva. El usuario podrá armar una topología con distintos componentes, ejecutar una simulación de tráfico y observar cómo responde el sistema en tiempo real.

## Problema que resuelve
Comprender el comportamiento de sistemas distribuidos y redes bajo distintas cargas suele ser difícil, ya que muchas veces estos temas se explican de forma teórica o requieren herramientas complejas e infraestructura real para ponerlos en práctica.

Nuestra propuesta busca ofrecer una herramienta simple y visual para experimentar con conceptos como latencia, cuellos de botella, saturación y fallos en componentes de una arquitectura.

## Usuarios
- Estudiantes universitarios de Sistemas, Informática o carreras afines
- Profesores que quieran una herramienta de apoyo para clases prácticas
- Desarrolladores junior que busquen entender mejor arquitecturas modernas

## Funcionalidades principales
- **Lienzo interactivo:** crear y conectar componentes como API Gateway, Load Balancer, servicios, caché y base de datos.
- **Simulación de tráfico:** ejecutar pruebas de carga simples sobre la arquitectura armada.
- **Monitoreo visual:** mostrar estados de los nodos y alertas cuando haya saturación o fallos.
- **Guardar topologías:** almacenar arquitecturas para volver a usarlas más adelante.

## Stack tecnológico
- **Frontend:** React.js
- **Backend:** Node.js o Python
- **Base de datos:** MySQL
