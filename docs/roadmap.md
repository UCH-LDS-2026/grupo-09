# Roadmap

| MVP actual | Próximo | Futuro | Fuera de alcance |
|---|---|---|---|
| Canvas para armar arquitecturas con API gateway, balanceador, servicio, cache, base de datos y cola. | Documentar el modelo de simulación con fórmulas y ejemplos defendibles. | Versionado de escenarios para comparar cambios entre simulaciones guardadas. | Reemplazar herramientas de load testing como k6 o JMeter. |
| Validación de conexiones y bloqueo de ciclos para mantener un grafo dirigido acíclico. | Medir volumen de datos con tamaño promedio de request y saturación por ancho de banda. | Curvas de latencia más progresivas y configurables por tipo de componente. | Monitorear sistemas reales en producción como Grafana. |
| Simulación de RPS, capacidad por instancias, throughput, colas, errores, latencia, costo y cuello de botella. | Mejorar la explicación visual de por qué un nodo queda en advertencia, alta carga, saturado o con errores. | Reportes exportables para documentar decisiones técnicas. | Calcular precios reales y actualizados de proveedores cloud. |
| Persistencia de proyectos en MySQL con nodos, conexiones y tráfico entrante. | Agregar defaults compatibles para proyectos viejos cuando aparezcan nuevos parámetros de simulación. | Biblioteca de plantillas de arquitectura comunes. | Simular comportamiento exacto de bases de datos, caches, redes o colas reales. |
| Autenticación, autorización básica por rol, rate limit, CSRF y headers de seguridad. | Mejorar pruebas de integración alrededor de guardado/carga de proyectos. | Colaboración multiusuario o comentarios sobre escenarios. | Ejecutar infraestructura real o desplegar servicios cloud desde la aplicación. |
